# Puzzle OS 

A fun, lightweight operating system that runs entirely in your web browser. Before you can get in, you have to bypass a retro green BIOS security gate by solving a quick 3-number puzzle. Once inside, you get a clean desktop with floating windows, retro mini-games, and desktop tools.

---

## What's Inside

* **Retro BIOS Gate**
* **Floating Window Desktop**
* **3×3 Tile Slide** 
* **Card Memory Match**
* **Notepad** 
* **Live Taskbar** 

---

## How to Run It

1. Create a folder on your computer named `puzzle-os`.
2. Save the three project files inside that folder:
   * `index.html`
   * `style.css`
   * `script.js`
3. Double-click `index.html` to open it in Chrome, Firefox, Safari, Edge, or any modern browser.

---

├── index.html   # Layout for BIOS, desktop, and floating windows
├── style.css    # Colors, fonts, CRT scanline glow, and layouts
└── script.js    # Window dragging, games logic, and system clock
